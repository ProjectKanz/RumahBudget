## Variant: Mobile-first Money Map

### Design stance
Start from the daily phone use case, not the desktop dashboard: “safe to spend” and buckets first.

### Inspiration
- Wise: bold green/black fintech energy and large confident typography.
- Mobbin: mobile-first finance apps usually optimize for one-handed quick checks and one primary action.
- Behance personal-finance dashboard results: bucket cards, AI finance manager patterns, and simple financial status summaries.

### Key choices
- Layout: marketing-style desktop shell around a realistic mobile app screen.
- Typography: bold and friendly, very readable.
- Color: lime green + black + white, intentionally memorable.
- Interaction: tab switch + quick-add toast.

### Trade-offs
- Strong at: daily usability, distinctive brand, easy demo story.
- Weak at: desktop data density is lower.

### Best for
If RumahBudget’s strongest product story is “personal finance assistant I actually use every day.”
