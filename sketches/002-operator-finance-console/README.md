## Variant: Operator Finance Console

### Design stance
Still cockpit-like, but cleaned up: high scan speed, structured data, no random neon/glass AI aesthetic.

### Inspiration
- Linear design language: dark-native surfaces, subtle borders, command palette pattern.
- Behance finance SaaS / Finance CRM results: dense KPI cards, ledgers, decision queues.
- Mobbin pattern library concept: real app flows often prioritize command/search + focused panels.

### Key choices
- Layout: three-column console with command bar, ledger center, decision queue right.
- Typography: Inter + JetBrains Mono only for labels/commands.
- Color: near-black, soft gray hierarchy, one violet accent.
- Interaction: right command drawer opens/closes.

### Trade-offs
- Strong at: power-user dashboard, auditability, serious portfolio vibe.
- Weak at: may still feel too technical for casual daily use.

### Best for
If RumahBudget should keep the “cockpit” identity but become more professional and less AI-generated.
